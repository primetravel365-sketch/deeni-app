# إدراج صوتَي الفجر المعتمدين في APK

الحزمة التي أعدّها المستخدم:
`islamiyat-approved-fajr-audio-package.zip`، وهي تحتوي على الملفين الأصليين دون تعديل.

## إجراء رفع واحد
في فرع `review/islamiyat-combined-nov2026` على GitHub اختر **Add file → Upload files**،
وارفع الحزمة أعلاه إلى **جذر المستودع** (بجوار `package.json`)، وليس إلى مجلد `www`.
ثم احفظ Commit على فرع المراجعة نفسه، دون دمج `main`.

## ماذا يحدث بعدها؟
عند كل بناء Android، ينفذ `node scripts/install-approved-fajr-audio.cjs`.
يفتح الحزمة في الذاكرة، ويستخرج **هذين الملفين فقط**:
- `android/app/src/main/res/raw/ali_ahmad_mulla_hq.mp3`
- `android/app/src/main/res/raw/fajr_khayr_min_al_nawm.mp3`

يفحص SHA-256 لكل ملف، ويرفض الحزمة إذا خالف أي ملف التسجيل الذي رفعه المستخدم.
إذا كانت الحزمة غير موجودة، يظهر تحذير واضح بأن صوت الفجر غير مكتمل.
لا يحذف أو يستبدل أي صوت أصلي آخر.

## شرط الفجر
العبارة: بعد اكتمال أذان الفجر، مرة واحدة يوميًا، وقبل موعد الإقامة المُعدّ في التطبيق، دون عرضها ضمن قائمة المؤذنين.
إن لم يكف الوقت المتبقي أو لم يتوفر التسجيل، تُتجاوز العبارة لتفادي التداخل. لا تعمل مع الصلوات الأخرى.

**تنبيه:** نجاح البناء البرمجي دون الحزمة لا يثبت وجود الصوتين في APK.
ولا يثبت حق إعادة التوزيع التجاري للتسجيلات؛ يلزم توثيق الترخيص قبل النشر العام.
