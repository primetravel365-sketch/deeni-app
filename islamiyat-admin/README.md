# تهيئة لوحة إدارة إسلاميات

1. داخل مشروع Supabase الحالي، نفّذ `setup.sql` من محرر SQL مرة واحدة.
2. أنشئ حسابك الإداري في Authentication → Users بالبريد وكلمة مرور قوية، ثم انسخ UUID الحساب.
3. من محرر SQL، عيّن صلاحية الإدارة لحسابك فقط باستبدال القيمة في الأمر التالي.

```sql
insert into islamiyat_admin.members (user_id) values ('ضع-معرّف-الحساب-هنا');
```

4. افتح `admin.html` من استضافة ويب خاصة بالإدارة أو خادم محلي. احفظ الملف خارج مجلد `www` الخاص بتطبيق إسلاميات.
5. جرّب الدخول بحساب الإدارة، ثم بحساب اختبار عادي. يجب أن يُرفض الحساب العادي وألا يستطيع قراءة الأكواد أو تعديلها.

اللوحة تدير إصدار الأكواد وتعطيلها. تفعيل الأكواد داخل التطبيق وتطبيق الخصومات على المدفوعات يحتاجان إلى ربط منفصل قبل توزيع الأكواد على المستخدمين.

## هدايا برايم في نسخة المراجعة

بعد التهيئة الأولى طبّق `redeem.sql` على مشروع Supabase الخاص بإسلاميات. استخدم بريد حساب الإدارة للدخول إلى `admin.html`، وأنشئ كودًا من نوع «استخدام مجاني مؤقت». أرسل الكود للمستخدم ليُلصقه في خانة برايم عند التسجيل أو بعد الدخول. تبدأ المدة عند الاسترداد، وتمتد الهدايا اللاحقة من نهاية المدة الحالية. جرّب كودًا محدودًا لاستخدام واحد بحساب اختبار بعد تأكيد بريده.

يمكن تعطيل الكود لمنع استخدامه من حسابات جديدة. تظل المدة الممنوحة سابقًا سارية. أكواد الخصم محفوظة في اللوحة للربط المستقبلي عند إضافة الدفع.
